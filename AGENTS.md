# AGENTS.md

## Rules

1. After every change is completed, you must create a corresponding Git commit so that changes can be tracked and rolled back later.
2. After every change, you must write or update the relevant tests, and make sure all tests and verifications pass before delivering the results to the user.
3. If a mistaken modification causes large-scale corruption of file contents, do not attempt to restore the files line by line — restore them from Git immediately. If the affected files are not under Git control, stop and report this situation to me.
